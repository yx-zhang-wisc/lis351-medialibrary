# MediaLibrary

A one-page personal media review website for LIS 351, Assignment 4.

## Open locally

Open `index.html` in a browser. The stylesheet and all illustrations are local; no installation or build is required.

## Website files

- `index.html`: semantic page structure and review content.
- `styles.css`: completed course CSS template, including desktop rows and mobile layouts.
- `images/`: four original SVG illustrations created for this website.
- `media-library-planning.md`: original A3 planning document.

The featured book review is sample editorial copy and can be personalized before submission. The recommendation button opens an email to the address in the original skeleton, `y-z@outlook.com`.

## Publish on GitHub Pages

Extract `media-library-website.zip` and upload its contents to your repository, with `index.html` at the repository root. Upload the actual website files rather than only the ZIP. Enable GitHub Pages for that branch and root folder in the repository settings. Once published, check the page, images, and links.

For Canvas, submit the ZIP and include both your live GitHub Pages URL and repository URL in the submission comment.

## Design and credits

The design follows the planning document's beige, slate gray, and forest green palette. All SVG artwork and inline icons are original, so the site does not rely on remote image services or icon libraries. The featured book links to Project Gutenberg; discovery links are retained from the original skeleton.
